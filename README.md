# KianDev — Brand Identity

> **Desarrollo sin límites.**

Repositorio maestro de la identidad visual de **KianDev**. Contiene los archivos vectoriales del logo, exportaciones PNG, favicon, tokens de color y una guía rápida de uso.

## Concepto

El símbolo combina **dirección, conexión y acceso** mediante una geometría abstracta. La lectura principal es una **K moderna y minimalista**; en una segunda lectura puede sugerir una **llave**, sin volverla literal.

## Tipografía

**Inter** es la familia tipográfica principal.

## Uso recomendado

- Web/app: SVG siempre que sea posible.
- Redes y documentos: PNG transparente.
- Navegador/app icon: archivos de `assets/favicon/`.
- Impresión o grabado: versiones monocromas.

La fuente maestra del logo es el SVG. Los PNG de este repositorio son exportaciones derivadas de esos vectores.
