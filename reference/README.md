# Referencia visual aprobada

La identidad se basa en la propuesta aprobada de KianDev: fondo azul noche, símbolo abstracto en violeta y azul, wordmark limpio, estética tecnológica premium y lectura secundaria sutil de llave.

La regla más importante es **no volver el símbolo una K obvia**. Debe conservar el espacio negativo y la sensación de dirección/conexión de la propuesta original.
